一、运行 / Run
完整解压 ZIP，运行 AI-Embedded-Paper-PDF-Reader.exe，保留所有同目录文件。
Fully extract the ZIP and run AI-Embedded-Paper-PDF-Reader.exe. Keep all accompanying files.
无需单独安装 Node.js。更新前正常退出旧版，不要同时运行两版。
No separate Node.js installation is needed. Exit the old version normally before updating; do not run both together.

二、阅读与语言 / Reading and language
首页选择本地 PDF，或继续最近阅读。相同内容只显示一次，同名不同内容分别保留。
Open a local PDF or continue a recent document. Identical content appears once; different content with the same filename remains separate.
左侧打开文件及文档导航；右侧阅读设置、聊天及关闭。文档导航包含目录、全文搜索和批注列表。
The toolbar provides file opening and navigation on the left, and reading settings, chat and close on the right. Navigation includes PDF contents, search and annotations.
在首页、阅读设置或模型设置中选择“简体中文 / English”，选择在本机记住。
Choose 简体中文 / English on the home screen or in reading/model settings. The choice is remembered locally.
切换只改变操作界面，不改写论文、聊天、笔记、已保存连接名称或回答偏好。
Switching changes only the interface, without rewriting papers, conversations, notes, saved connection names or answer preferences.

三、批注和高亮颜色 / Annotations and highlight colors
划选文字，选择询问 AI 或只写批注。点击高亮打开，× 或框外点击收起，拖动标题栏可移动。
Select text to ask AI or write a note. Click a highlight to open it, close with × or an outside click, and drag the title bar to move it.
批注框的“高亮颜色”提供八种预设、自定义颜色选择器和 #RRGGBB / #RRGGBBAA 输入。颜色随批注保存、备份和恢复。
Highlight color offers eight presets, a custom color picker and #RRGGBB / #RRGGBBAA input. Colors survive annotation save, backup and restore.
每处高亮保留一组当前问答。可编辑或重新提问，新回答成功后才覆盖旧结果；失败或停止仍保留旧结果。
Each highlight has one current Q&A. Edit it or ask again. Only a successful new answer replaces the old result; failure or stopping keeps it.
重新生成主回答创建独立版本，旧批注留在原回答上。批注内不创建嵌套批注。
Regeneration creates a separate answer version; old annotations stay on the original. Annotations have no nested annotations.

四、阅读配色 / Reading colors
阅读设置可选择原色、暖黄、浅灰、深色或自定义纸张/文字色。可保留彩图及临时对照原色。
Reading settings offer original, warm yellow, light gray, dark or custom paper/text colors. Preserve colored areas or temporarily compare original colors.
工具栏、阅读区边缘、设置与批注框随纸张色变化，拖动先快速预览，停下后恢复清晰。换色只改变显示，不改写 PDF。支持连续/单页、双指捏合或 Ctrl + 滚轮缩放及续读。
The toolbar, reader margins, settings and annotations follow the paper color. Dragging uses a fast preview and restores full clarity when settled. Recoloring changes the display only. The reader supports continuous/single pages, trackpad pinch or Ctrl + wheel zoom, and reading position memory.
扫描页可查看及换色，暂不支持 OCR 或图像理解。目录依赖文件内嵌结构，搜索使用提取文字。
Scanned pages support viewing and recoloring, without OCR or image understanding. Contents depend on embedded outlines; search uses extracted text.

五、模型与网络 / Models and networking
首页直接显示 API 连接。打开配置，填写地址和密钥后点击“探测模型”，筛选选择模型再保存；不支持列表的服务仍可手动填写。可用中转站、GPT、Claude、DeepSeek 或“其他”服务模板。
The home screen shows API setup. Enter the address and key, fetch available models, filter/select a model and save. Manual entry remains available when listing is unsupported. Choose relay, GPT, Claude, DeepSeek or Other service templates.
其他服务包含 Kimi、千问、Gemini 兼容入口、Grok、Ollama、LM Studio 和自定义 API。
Other services include Kimi, Qwen, Gemini's compatible endpoint, Grok, Ollama, LM Studio and custom APIs.
接口格式是通信协议：Chat Completions、Responses、Anthropic Messages。模型名称和可用性由服务商决定。
API formats are protocols: Chat Completions, Responses and Anthropic Messages. Model names and availability depend on the provider.
保存或切换连接不发送问题。普通阅读、搜索和笔记不调用 AI。
Saving/switching connections sends no questions. Reading, searching and personal notes make no AI requests.
发送问题会发送完整有效主对话；附件默认小文件全文、大文件按需引用，另带选中文字及所在页片段。原文件留在本机。自动模式在超过 25 MiB、300 页或 12 万提取字符时使用本地关键词检索，每份引用片段最多 2.4 万字符；选区和对话另计。阅读设置可切换全文或按需引用，工具栏显示范围。失败重试沿用首次请求的资料；资料不足会明确提示，全文仍受请求与模型容量限制，不静默截断主对话。
Asking sends the full valid main conversation. Auto mode sends full extracted text for small files and locally retrieved excerpts for large files, plus the selection and passages from its page. Original files stay local. Above 25 MiB, 300 pages or 120,000 extracted characters, local keyword retrieval selects up to 24,000 excerpt characters per file; the selection and conversation are additional. Reading settings can override this scope, shown in the toolbar. Failed requests retry with their original material. Missing evidence is disclosed; full text remains subject to request and model capacity, without silently truncating the main conversation.
桌面版沿用系统代理，不含代理节点或密钥。使用代理时保持代理工具运行并开启系统代理；API 地址仍填服务商地址。
The desktop app follows the system proxy and includes no proxy nodes or keys. Keep your proxy app and system proxy enabled when needed, and keep the provider's address in the API field.

六、数据、备份和退出 / Data, backups and exit
更名继续使用原数据位置 %APPDATA%\MarginChat，不需要迁移或重填已保存连接。
Renaming keeps the original data location, %APPDATA%\MarginChat. No data migration or re-entry of saved connections is needed for this rename.
“备份与恢复”支持完整导出、当前对话导出、兼容旧版导出、自动备份及恢复为新对话。
Backup & restore supports full/current-conversation export, legacy export, automatic backups and restoration as new conversations.
备份包含附件原文件和批注，不含 API 配置或密钥。界面语言、阅读配色和位置是单独的本机偏好，不进入聊天备份。
Backups contain original attachments and annotations, but no API settings/keys. Language, reading colors and position are separate local preferences outside conversation backups.
回收站可恢复、永久删除或清空；以前的自动或导出备份可能仍包含旧内容。
Trash supports restore, permanent deletion and emptying. Earlier automatic/exported backups may still contain old content.
正常关闭等待保存和备份完成。保存失败可重试或取消退出，强制结束可能丢失最近修改。
Normal exit waits for saving and backup. Retry or cancel exit if saving fails; forced termination may lose recent edits.
启动无反应可运行“启动诊断.cmd”。反馈前去除个人路径、内容和密钥，不要发送整个数据目录或模型配置。
If startup fails, run 启动诊断.cmd. Remove personal paths/content/keys before reporting; do not share your whole data directory or model settings.

大文件 / Large files
PDF 最大 150 MiB、5000 页、1000 万提取字符；文字文件最大 25 MiB、100 万字符。打开时可查看提取进度并取消。全工作区备份仍以 350 MB 为限，超出时分别导出对话。
PDF: up to 150 MiB, 5,000 pages and 10 million extracted characters. Text files: up to 25 MiB and 1 million characters. Opening shows progress and supports cancellation. Full-workspace backups retain a 350 MB limit; export conversations separately when needed.


模型探照说明 / Model discovery details

首页“探测上游模型”直接进入列表获取，已保存可用连接会自动读取。使用服务商的 GET 模型列表 API，不是管理后台网页。兼容以 /responses、/chat/completions、/messages 或 /models 结尾的完整地址；推导列表路径时保留主机与前缀，不改保存的连接或密钥。界面显示请求路径及 HTTP 失败状态，仍可手动填模型名。

Discover models on the home screen opens discovery and fetches immediately for a usable saved connection. It uses the provider's GET model-list API, rather than a management webpage. Full /responses, /chat/completions, /messages and /models addresses are accepted; the provider prefix/origin and saved connection/key are preserved. The UI shows the request path and HTTP failure status, with manual model entry available.


模型选择 / Model selection
连接名称只作本地备注；在上游模型下拉框中选择实际调用模型，保存并使用后生效。模型按名称及自然数字顺序排列，手动输入按需展开，保留未列出的自定义模型。

Connection names are local labels. Choose the actual API model in the upstream list and Save and use. Models sort by name with natural numbers; manual entry expands on demand and preserves unlisted custom models.
