learn something 0.1.9 · Windows x64

一、运行与升级
1. 退出正在运行的旧版客户端（原名“页边 Margin”）。
2. 将 LearnSomething-0.1.9-Windows-x64.zip 全部解压到一个新文件夹。
3. 运行其中的 LearnSomething.exe，并保留同文件夹中的所有运行组件。
4. 桌面界面左上角显示 learn something，顶部版本标记为 0.1.9 · 20261105.3。
5. 首次读取旧聊天时，会先生成含附件的升级前备份，再转换保存方式；等待完成后即可使用。备份失败时原记录保持不变。

无需单独安装 Node.js，无需管理员权限。请直接运行解压后的 EXE，不要在压缩包内运行或只复制 EXE。

二、本版变化
0.1.9：多条批注共用不可变的完整上下文，生成中仅保存变化记录，合并过期保存任务。百万字符资料配 10 条批注的合成文字记录约从 11 MB 降至 2 MB；不减少发送给模型的完整上下文。
“备份与恢复”可选择全部记录或当前对话，默认导出紧凑备份，并提供“兼容旧版导出”。保留独立的 0.1.8 程序文件夹。

0.1.8 新增：已回答批注可点击“重新提问”，新回答成功后覆盖旧问答；失败或停止保留旧内容。
回收站支持对话和批注的恢复、永久删除和清空；永久删除对话会清理其附件原文件。删除前须确认，历史自动和导出备份仍可能保留旧内容。

沿用的稳定性功能：批注有独立“停止回答”，× 只收起窗口；停止后可重试原问题和首次上下文。创建和导入操作预先检查保存容量。保留本机自动备份、恢复入口和退出保存等待。

此前已修复：长表格按完整内容撑开，不再覆盖后续正文；按住批注框顶部标题栏可以拖动，方向键也能移动；正文与高亮文字保持文字光标。关闭后再次打开仍默认定位到原文。
程序更名为 learn something。聊天区、侧栏、批注框、设置和文件阅读控件改为柔和的暖黄色调，正文使用深棕色。PDF 原页可单独换色并对照原色；不同批注仍用不同高亮色区分。

旧版的聊天、批注、文件和模型配置继续保存在原来的位置：
%APPDATA%\MarginChat
名称变化不需要迁移这份数据。请不要删除该目录；不要同时打开新旧两版。

三、使用自己的模型
打开“模型与设置”，可预载 GPT 官方、Claude 官方、DeepSeek 或中转站。
按服务商说明填写 API 地址、接口格式、模型名和自己的密钥，点击“保存并使用”。
保存后在输入框左下角切换模型；切换不改变已有回答。
已有配置会继续读取，无需因本次更名重新填写密钥。

若使用 Clash 等代理工具，请保持工具运行并开启 Windows 系统代理。
模型 API 地址仍填写服务商的 API 地址，不要改成代理的本机地址。
本版继续使用 0.1.5 加入的系统代理支持。

四、阅读与批注
可在回答中划选文字，选择“询问 AI”或“只写批注”。
保存后原文保留高亮，点击高亮打开；点击框外或右上角 × 可收起批注。
询问模式每处高亮只保留一组当前问答，可编辑或重新提问并在成功后覆盖；普通笔记不调用 AI。
通过输入框附近的附件入口导入 PDF、TXT、Markdown，即可在本机阅读和批注。
PDF 原排版支持翻页、缩放和文字划选；扫描件可看，暂不包含 OCR。
网络或 API 失败后可以重试，也可以直接继续发送新的主对话问题。

五、备份与诊断
通过侧栏“备份与恢复”导出当前记录、查看自动备份或从文件恢复；“导入”或正常界面恢复会追加为新对话，不覆盖原聊天。
桌面在内容保存后及退出前自动备份，在持续输出时每分钟保留检查点，最近 5 份完整备份保存在 %APPDATA%\MarginChat\Backups。
升级前的旧版兼容文件另外保留最近 2 份，不参与普通 5 份轮换。新版可读旧备份，旧版不能直接读取新版紧凑格式。
如需回退：先在新版“备份与恢复”选择“兼容旧版导出”，关闭新版，再在 0.1.8 的恢复入口恢复该文件。也可恢复标为“升级前备份”的副本，但其中没有升级后的修改。不要同时运行两版。
备份完成后才轮换旧文件，恢复前校验内容；若本地记录读取失败，可在错误页选择“从备份恢复”，原记录另外保留最近 3 份本地副本。
正常退出等待写入和备份完成；若未能完成，会提供重试、取消和直接退出选项。请使用窗口关闭按钮退出，强制结束进程只能恢复到之前已完成的保存或检查点。
备份包含附件原文件和批注，不包含模型配置或密钥。
若启动无反应，运行同目录“启动诊断.cmd”，等待约 20 秒查看“启动诊断”文件夹。
若模型回答失败，可将界面上的错误提示和诊断编号反馈给开发者。
请求日志位于 %APPDATA%\MarginChat\logs\requests.jsonl，不记录密钥或聊天正文。
请勿把 model-profiles.json、整个数据目录或密钥发给别人。

六、阅读模式与页面配色
侧栏点击“打开文件阅读”，或点击对话中的已有文件，进入专注阅读。右上角“显示聊天”可返回并排聊天，小窗口会返回聊天页；× 关闭文件。
点击“阅读配色”，选择原色、暖黄、浅灰、深色，或自选纸张和文字颜色；HEX 输入支持 #RRGGBB。
“原色对照”临时查看 PDF 原样，再点一次恢复。换色只改变显示，不改写原文件。
保留彩色区域时，彩色图表保留颜色，黑白灰随配色改变。扫描页在深色下若文字偏暗，可关闭“保留彩色区域”让整页换色；本版仍不提供 OCR。
配色会在本机记住，每份文档分别记住页码、缩放和阅读位置。再次打开已有附件可恢复；这些阅读设置不随聊天备份导出。
本次升级到 0.1.9，聊天、附件、批注与加密模型配置继续沿用；聊天保存格式会按上述流程安全转换。

七、PDF 文字选取修复
已修正多行摘要拖选不全、起点偏移和短行末尾跳到前文的问题。按住鼠标左键可正向或反向划选，拖至阅读区域边缘会继续滚动；双击选词、右键复制和添加批注继续可用。
缩放、翻页或切换阅读布局后会重新对齐选取位置。已有高亮和批注继续按原文保存，不需要重新导入文件。
