# 首个公开正式版

首个公开正式版使用版本 `v0.1.11`，应用构建为 `20261105.10`。本次开放已有客户端代码，并补充 MIT 许可证、数据说明和发布包内的许可文件，不改变阅读、批注、网络请求或个人数据格式。

## 公开前检查

公开前对既有全部 11 个远端分支和其可达的 13 个提交逐项核对，审阅 268 个不同文件内容对象、1,334 项历史文件条目与提交作者信息；远端提交和文件树与本地 Git 对象一致。

检查未发现实际 API 密钥、私钥、聊天记录、个人论文、用户绝对路径、真实模型配置、代理订阅或公网 IP。疑似凭证逐项确认是用于日志脱敏、模拟接口、环境注入和导入校验的虚构测试数据。唯一 IPv4 字面量为回环地址 `127.0.0.1`。

作者使用 GitHub 公开账号及 GitHub 提供的 noreply 邮箱。依赖锁文件中的开源维护者邮箱和测试 URL 中的虚构用户信息不属于使用者的私人资料；第三方版权与许可声明继续保留。

公开前未发现 GitHub Actions 历史、历史 Release 附件或 Issues。新增许可与公开说明另外按源码白名单核对。忽略规则和内容检查同时使用，不以 `.gitignore` 代替历史审阅。

## 发行包

- 仅分发完整 Windows x64 ZIP 和对应 SHA-256 校验文件，不上传本机用户数据目录。
- ZIP 包含项目 MIT 许可证、Electron / Chromium 许可及第三方声明。
- 正式应用的 EXE 与程序归档保持已验证构建的字节；公开整理只增加许可和通用说明文件。
- 应用构建已通过 215 项现有检查、551 项交付核对和隔离的实际启动、保存、完整备份及正常退出验证。新增许可文件与 ZIP 结构另行校验。

完整机器检查结果保留在本机，不把本机环境、代理节点或测试资料发布为附件。公开检查针对已核对的提交和发行文件；以后新增代码、日志或附件需重新检查。
