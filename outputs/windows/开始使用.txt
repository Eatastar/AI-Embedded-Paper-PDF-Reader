AI-Embedded Paper PDF Reader

一、运行 / Run
完整解压 ZIP，运行 AI-Embedded-Paper-PDF-Reader.exe，保留所有同目录文件。
Fully extract the ZIP and run AI-Embedded-Paper-PDF-Reader.exe. Keep all accompanying files.
无需单独安装 Node.js。更新前正常退出旧版，不要同时运行两版。
No separate Node.js installation is needed. Exit the old version normally before updating; do not run both together.

二、阅读与语言 / Reading and language
首页选择本地 PDF，或继续最近阅读。相同内容只显示一次，同名不同内容分别保留。
Open a local PDF or continue a recent document. Identical content appears once; different content with the same filename remains separate.
左侧打开文件及文档导航；右侧阅读设置、聊天及关闭。文档导航包含目录、全文搜索和批注列表。
The toolbar provides file opening and navigation on the left, and reading settings, chat and close on the right. Navigation includes PDF contents, search and annotations.
在首页、阅读设置或模型设置中选择“简体中文 / English”，选择在本机记住。
Choose 简体中文 / English on the home screen or in reading/model settings. The choice is remembered locally.
切换只改变操作界面，不改写论文、聊天、笔记、已保存连接名称或回答偏好。
Switching changes only the interface, without rewriting papers, conversations, notes, saved connection names or answer preferences.

三、批注和高亮颜色 / Annotations and highlight colors
划选文字，选择询问 AI 或只写批注。点击高亮打开，× 或 Esc 收起，点击聊天或正文保持打开，拖动标题栏可移动。
Select text to ask AI or write a note. Click a highlight to open it, close with × or Esc, keeping it open when clicking chat or source text, and drag the title bar to move it.
批注框的“高亮颜色”提供八种预设、自定义颜色选择器和 #RRGGBB / #RRGGBBAA 输入。颜色随批注保存、备份和恢复。
Highlight color offers eight presets, a custom color picker and #RRGGBB / #RRGGBBAA input. Colors survive annotation save, backup and restore.
每处高亮保留一组当前问答。可编辑或重新提问，新回答成功后才覆盖旧结果；失败或停止仍保留旧结果。
Each highlight has one current Q&A. Edit it or ask again. Only a successful new answer replaces the old result; failure or stopping keeps it.
重新生成主回答创建独立版本，旧批注留在原回答上。批注内不创建嵌套批注。
Regeneration creates a separate answer version; old annotations stay on the original. Annotations have no nested annotations.

四、阅读配色 / Reading colors
阅读设置可选择原色、暖黄、浅灰、深色或自定义纸张/文字色。可保留彩图及临时对照原色。
Reading settings offer original, warm yellow, light gray, dark or custom paper/text colors. Preserve colored areas or temporarily compare original colors.
放大或滚动后，可视区域会自动补上高清绘制。整页底图继续控制内存占用，屏幕外不保留高清缓存；文字选择、引用跳转及批注位置使用原来的文字层。
After zooming or scrolling, visible areas automatically receive a high-resolution redraw. The bounded whole-page bitmap remains available, while offscreen detail caches are released. Selection, reference navigation and annotation positions continue to use the original text layer.
深色纸张会将 PDF 自带链接的文字及边缘统一调整为柔和浅蓝色，减少引用数字的白色重影。图片链接不会整体换色，原色对照可恢复原来的颜色。
On dark paper, embedded PDF link text and its edges share a soft light blue to prevent pale citation halos. Image links are not recolored as a whole, and original-color comparison restores the source colors.
工具栏、阅读区边缘、设置与批注框随纸张色变化，拖动先快速预览，停下后恢复清晰。换色只改变显示，不改写 PDF。支持连续/单页、双指捏合或 Ctrl + 滚轮缩放及续读。
The toolbar, reader margins, settings and annotations follow the paper color. Dragging uses a fast preview and restores full clarity when settled. Recoloring changes the display only. The reader supports continuous/single pages, trackpad pinch or Ctrl + wheel zoom, and reading position memory.
扫描页可查看及换色，暂不支持 OCR 或图像理解。目录依赖文件内嵌结构，搜索使用提取文字。
Scanned pages support viewing and recoloring, without OCR or image understanding. Contents depend on embedded outlines; search uses extracted text.

五、模型与网络 / Models and networking
首页直接显示 API 连接。打开配置，填写地址和密钥后点击“探测模型”，筛选选择模型再保存；不支持列表的服务仍可手动填写。可用中转站、GPT、Claude、DeepSeek 或“其他”服务模板。
The home screen shows API setup. Enter the address and key, fetch available models, filter/select a model and save. Manual entry remains available when listing is unsupported. Choose relay, GPT, Claude, DeepSeek or Other service templates.
其他服务包含 Kimi、千问、Gemini 兼容入口、Grok、Ollama、LM Studio 和自定义 API。
Other services include Kimi, Qwen, Gemini's compatible endpoint, Grok, Ollama, LM Studio and custom APIs.
接口格式是通信协议：Chat Completions、Responses、Anthropic Messages。模型名称和可用性由服务商决定。
API formats are protocols: Chat Completions, Responses and Anthropic Messages. Model names and availability depend on the provider.
保存或切换连接不发送问题。普通阅读、搜索和笔记不调用 AI。
Saving/switching connections sends no questions. Reading, searching and personal notes make no AI requests.
聊天发送尚未删除的有效主对话及所选文档资料，默认不读取批注；点击输入框下方工具栏“引用批注”后，只把手动选择的问答或笔记加入该次问题。PDF 批注只引用所属文档、选段和本次问题，不带聊天及其他批注；在 AI 回答上提问时，仅引用批注绑定的那一版原回答。
文档范围继续支持自动、全文或按需引用：自动模式下，小文件发送全文提取文字，超过 25 MiB、300 页或 12 万提取字符时在本机检索，每份文档最多引用 2.4 万片段字符，选段和问题另计。原 PDF 和页面图片不作为文件上传。资料不足时明确提示，全文仍受请求和模型容量限制。批注失败重试保留本次问题、回答偏好和文档范围，从同一份不可变来源重新组装请求，不保存整段聊天快照。
Chat sends the remaining valid main conversation and document material, without automatically reading annotations. Reference annotations in the composer toolbar adds only the Q&A or notes you select to that question. A PDF annotation uses only its own document, selection and current question, without chat or other annotations. An annotation on an AI answer uses only its bound original answer version.
Document scope still supports Auto, Full text and Relevant excerpts. Auto sends full extracted text for small files; above 25 MiB, 300 pages or 120,000 extracted characters, local retrieval sends at most 24,000 excerpt characters per document, with the selection and question additional. Original PDFs and page images are not uploaded as files. Missing evidence is disclosed, and full text remains subject to request/model limits. Failed annotation retries retain the question, answer preference and document scope and rebuild from the same immutable source, without storing a full-chat snapshot.
桌面版沿用系统代理，不含代理节点或密钥。使用代理时保持代理工具运行并开启系统代理；API 地址仍填服务商地址。
The desktop app follows the system proxy and includes no proxy nodes or keys. Keep your proxy app and system proxy enabled when needed, and keep the provider's address in the API field.

六、数据、备份和退出 / Data, backups and exit
更名继续使用原数据位置 %APPDATA%\MarginChat，不需要迁移或重填已保存连接。
Renaming keeps the original data location, %APPDATA%\MarginChat. No data migration or re-entry of saved connections is needed for this rename.
“备份与恢复”支持完整导出、当前对话导出、兼容旧版导出、自动备份及恢复为新对话。
Backup & restore supports full/current-conversation export, legacy export, automatic backups and restoration as new conversations.
备份包含附件原文件和批注，不含 API 配置或密钥。界面语言、阅读配色和位置是单独的本机偏好，不进入聊天备份。
Backups contain original attachments and annotations, but no API settings/keys. Language, reading colors and position are separate local preferences outside conversation backups.
回收站可恢复、永久删除或清空；以前的自动或导出备份可能仍包含旧内容。
Trash supports restore, permanent deletion and emptying. Earlier automatic/exported backups may still contain old content.
正常关闭等待保存和备份完成。保存失败可重试或取消退出，强制结束可能丢失最近修改。
Normal exit waits for saving and backup. Retry or cancel exit if saving fails; forced termination may lose recent edits.
启动无反应可运行“启动诊断.cmd”。反馈前去除个人路径、内容和密钥，不要发送整个数据目录或模型配置。
If startup fails, run 启动诊断.cmd. Remove personal paths/content/keys before reporting; do not share your whole data directory or model settings.

大文件 / Large files
PDF 最大 150 MiB、5000 页、1000 万提取字符；文字文件最大 25 MiB、100 万字符。打开时可查看提取进度并取消。全工作区备份仍以 350 MB 为限，超出时分别导出对话。
PDF: up to 150 MiB, 5,000 pages and 10 million extracted characters. Text files: up to 25 MiB and 1 million characters. Opening shows progress and supports cancellation. Full-workspace backups retain a 350 MB limit; export conversations separately when needed.


模型探照说明 / Model discovery details

首页“探测上游模型”直接进入列表获取，已保存可用连接会自动读取。使用服务商的 GET 模型列表 API，不是管理后台网页。兼容以 /responses、/chat/completions、/messages 或 /models 结尾的完整地址；推导列表路径时保留主机与前缀，不改保存的连接或密钥。界面显示请求路径及 HTTP 失败状态，仍可手动填模型名。

Discover models on the home screen opens discovery and fetches immediately for a usable saved connection. It uses the provider's GET model-list API, rather than a management webpage. Full /responses, /chat/completions, /messages and /models addresses are accepted; the provider prefix/origin and saved connection/key are preserved. The UI shows the request path and HTTP failure status, with manual model entry available.


模型选择 / Model selection
连接名称只作本地备注；在上游模型下拉框中选择实际调用模型，保存并使用后生效。模型按名称及自然数字顺序排列，手动输入按需展开，保留未列出的自定义模型。

Connection names are local labels. Choose the actual API model in the upstream list and Save and use. Models sort by name with natural numbers; manual entry expands on demand and preserves unlisted custom models.

划词翻译与 PDF 链接 / Translation and PDF links

选中文字后右键翻译或按默认 Alt+1；右上角独立“翻译”按钮可设置目标语言、提示词、独立 API 及自定义快捷键。连接列表共用，翻译选择不切换聊天。只发送选段和翻译提示词，不发送全文、所在页或聊天历史。临时面板显示译文和模型，框外点击、Esc 或 × 关闭并丢弃；点击保留后才创建普通批注。翻译设置单独记在本机，不进入聊天备份。

Select text and right-click to translate or press Alt+1. The separate Translate button configures the target language, prompt, independent API and shortcut. Connections are shared without switching chat. Only the selection and translation prompt are sent, without full text, page or history. Outside click, Esc or × discards temporary text/model results; Keep creates a plain note. Settings stay local outside conversation backups.

PDF 自带的参考文献和图号链接支持文内精确跳转，并可返回跳转前位置。HTTP/HTTPS 网页链接交由系统浏览器打开，不执行脚本或文件动作；没有原生链接的文字不猜测跳转。深色配色修正彩色字边缘的白色残影，原 PDF 不改写。

Embedded PDF references/figure links navigate to their page positions, with return navigation. HTTP/HTTPS links open in the system browser; scripts and file actions are not executed. No destination is guessed for unlinked text. Dark colors correct white halos around colored text without modifying the PDF.

翻译滚动保留 / Translation while scrolling
滚动时保留翻译框，连续阅读暂留当前翻译的来源页，滚远后仍可保留为原位置的批注。普通框外点击、Esc 或 × 关闭，拖动滚动条不会关闭。

The translation panel remains open while scrolling, retaining its source page in continuous reading so it can still be saved as a note at the original passage. Ordinary outside click, Esc or × closes it; dragging the scrollbar does not.

八、聊天引用与删除 / Chat references and deletion
输入框下方工具栏“引用批注”可以选择当前记录中已保存的问答或笔记，发送后可展开查看当时的副本。
Reference annotations in the composer toolbar selects saved Q&A or notes in the current record; expand the sent question to inspect its copy.
每轮回答下方的“删除本轮”会直接删除本轮问题、全部回答版本及这些回答上的批注，不进入回收站；PDF 原文批注和文件保留。同时清除剩余失败回答的旧请求快照，后续聊天中对被删回答批注的手动引用也会移除，重试不会通过这些缓存带回已删内容。以前的自动备份、迁移存档和导出文件可能仍含旧内容。
Delete round under each answer permanently removes that question, all answer versions and annotations attached to those answers, without Trash. PDF annotations and files remain. Remaining failed-answer snapshots and later manual references to the removed answer annotations are also cleared, so retries cannot restore deleted content through these caches. Earlier automatic backups, migration archives and exports may still contain old content.
0.1.20 可读取旧备份；含新增引用和重试设置的备份，请使用 0.1.20 或更新版本恢复。
Version 0.1.20 reads older backups; restore backups with new references/retry settings using v0.1.20 or newer.

九、重开 PDF 与引用文字 / Reopen PDF and quote text
聊天模式关闭 PDF 后保持聊天可见，顶部“展开 PDF”及聊天文件名可一键恢复并排阅读，沿用原页码与缩放。左上角长项目名按侧栏宽度换行。选中 PDF、AI 回答或聊天问题中的文字，可通过浮动按钮或右键“引用到聊天”，在输入框预览选段、补充问题再发送，不创建批注或自动调用 API。每次引用一段，重新选择会替换待发送段落，可用 × 取消。
Closing a PDF in chat keeps the conversation visible. Open PDF at the top, or the file name in chat, restores side-by-side reading with the saved page and zoom. Long branding wraps inside the sidebar. Select text in a PDF, AI answer or chat question and use Quote in chat from the selection action or context menu, preview the excerpt, add a question and send. This creates no annotation and makes no automatic API call. One pending excerpt can be replaced or removed with ×.
批注在点击聊天、正文、翻页和切换阅读布局时保持打开，用 × 或 Esc 收起；编辑中的修改在关闭或切换来源时保存。切换文件或对话会收起批注。临时翻译继续保持原来的框外点击、Esc / × 关闭及滚动保留规则；同时展开时，Esc 优先关闭翻译。
Annotations stay open while clicking chat/source text, turning pages or changing reading layout; use × or Esc to close. Pending edits are saved when closing or leaving the source. Switching documents or conversations dismisses the annotation. Temporary translation retains outside-click, Esc/× dismissal and scroll retention; when both panels are open, Esc dismisses translation first.
文字引用与本轮问题一起保存和备份，聊天仍按原设置带入有效聊天与文档资料。它与“只发送选段”的翻译功能不同；批注提问仍不引用聊天或其他批注。删除被引用的聊天轮次时，后续问题中的相关文字引用副本与旧重试缓存也会清除，PDF 引用和原文批注保留。新版本可读取旧备份，含文字引用的备份请使用 v0.1.22 或更新版本恢复。
Text quotations are saved and backed up with the question. Chat still uses valid history and document material according to existing scope settings, unlike selection-only translation. Annotation questions still exclude chat and other annotations. Deleting a quoted chat round clears its later quotation copies and stale retry snapshots while retaining PDF quotations and annotations. Older backups remain readable; restore backups with text quotations using v0.1.22 or newer.


聊天与阅读切换 / Switching between chat and reading
聊天关闭 PDF 后，顶部“展开 PDF”恢复并排阅读，“阅读模式”直接返回专注阅读。两者均恢复原页码和缩放。文件栏右侧显示“展开 / 收起”和矢量箭头。
After closing a PDF in chat, Open PDF restores side-by-side reading, while Reading mode returns to focused reading; both retain page and zoom. The file bar displays Expand / Collapse beside a vector chevron.

公式显示 / Math rendering
本版统一公式渲染器与本地样式版本，修复聊天、批注和翻译中不等号等否定符号的斜线错位。旧回答重新显示即可，无需重新生成。
This version aligns the math renderer with its local stylesheet, fixing negated relations in chat, annotations and translations. Existing answers display correctly without regeneration.
